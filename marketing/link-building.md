# Link Building — Community Presence Pipeline

*Infrastructure for building genuine inbound links + brand mentions via Yagel's accounts in Chrome (Claude extension). Started 2026-07-29.*

## Working protocol
1. **Yagel**: logs into accounts in Chrome, grants site permissions in the Claude extension, clicks any human-verification checks.
2. **Claude**: finds relevant threads/questions, reads them, drafts genuinely helpful answers per `content-playbook.md` §1 (human voice, no AI-isms, real specifics, light disclosure when linking our own site).
3. **Yagel approves each post in chat** → Claude submits it in the browser.
4. Every placed link/post is logged in the table below.

## Rules (non-negotiable)
- Answer must be genuinely helpful WITHOUT the link — the link is a bonus, not the point.
- Max 1 link per answer; link to the relevant guide on ai-manifest.com, not the App Store.
- Light disclosure when linking our own site ("my site" / "I wrote this up").
- Never mass-post; 2-3 quality contributions per week per platform max.
- Respect each community's self-promo rules; if a mod removes something, don't repost.
