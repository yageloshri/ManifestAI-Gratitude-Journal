# Community Field Guide — Anti-Flag Rules + Native Writing

*Condensed from deep research 2026-07-29. Full sources in research transcript. This guide governs ALL community posting (Reddit/Quora/Pinterest). Read together with `link-building.md`.*

## A. Reddit hard rules (mechanical)

**Detection layers:** site-wide ML spam filter (account age, karma, post:comment ratio, velocity, same-domain repetition), hidden CQS trust score (verify email! no VPN posting), per-sub AutoMod + Crowd Control (collapses comments from users with no history in that sub).

**Domain protection for ai-manifest.com (a domain ban is ~irreversible):**
- Max **1–2 ai-manifest.com links per week across ALL of Reddit**, ≥24h apart, never same URL twice in a short window
- Only ever from Yagel's one real account. NEVER from any other account. No URL shorteners, no UTM-heavy links
- Prefer mentioning without linking; site link lives in Reddit profile (profile links are never spam-filtered)
- After any link comment: check it logged-out (private window). If silently removed → stop linking 2–4 weeks, politely message mods, never repost

**Cadence (account is real but has little sub-specific history):**
| Phase | When | Do |
|---|---|---|
| Warm | weeks 1–4 | comments only in target subs, 15–30 min/day, zero links (not even others'), vary times of day |
| Establish | weeks 4–8 | first text posts (questions/experiences), still no own-domain links |
| Share | ongoing | 1 self-link per 10–19 genuine contributions; ≤1–2/week |

- Per-sub rate limit: low karma in a sub = 1 comment/~10 min. Slow is human.
- Velocity > volume. Irregular hours, quiet days, occasional disagreement = human.
- Links in comment replies (when someone asked) ≫ link posts.
- Always disclose ("I built this") — increases trust, and hiding affiliation is what gets reported.

**The 5 marketing tells (never do):** thin account + link; generic praise + link; same link across threads; comment that dies if you delete the link; suspiciously polished always-on-topic history. Keep some non-manifestation activity (iOS dev subs, hobbies) — makes "I'm a dev, I built this" credible.

## C. Native-register cheat sheet

**Meta: what gives AI away is register, not vocabulary** — flawless orthography in sloppy spaces, essay structure, em-dashes, zero discourse particles, zero lived detail, generic empathy openers. Every language has a word for AI prose: "lero-lero" (pt), "texto sin alma" (es), "fehlende Haltung" (de), "texte plat" (fr).

- **EN reddit:** lowercase openers, contractions, fragments, experience-first-advice-second, one mild hedge max (tbh/fwiw/ymmv), a concrete slightly-irrelevant detail, occasional imperfection, 1–3 sentence paragraphs. NEVER: "Great question!", bullets in comments, em-dashes, "it's not just X — it's Y", tidy conclusions.
- **pt-BR:** vc, tb, pq, tá, pra, né, mano/cara, tipo, "a gente", kkkk (never lol). Warmth-first ("passei por isso tbm"). Advice = shared experience, never instruction. NEVER: "É importante notar que", perfect accents + zero abbreviations, pt-PT words (fixe).
- **es (LatAm):** jaja, bueno/pues/o sea/la verdad/ojo, dropped opening ¿, q/xq/tmb, diminutives, "a mí me funcionó", tú. NEVER: perfect ¿…? everywhere, "fundamental/crucial", raya (—), usted, calques.
- **de:** Modalpartikeln = THE fingerprint (halt, eben, mal, doch, ja, schon), du immer (Sie = instant tell), kA/vllt/mMn/iwie, casual lowercase, visible skepticism. Bluntest culture; admitted imperfection = credibility. German esoteric scene lives on classic forums (Esoterikforum.at/.de) more than Reddit.
- **fr:** drop the "ne" (je sais pas), on not nous, t'as/y'a, du coup/franchement/perso/bah/bref/en vrai, mdr/tkt, tutoiement. Native move on manifestation: testimony + nod to skepticism ("perso ça a marché, après chacun voit hein"). NEVER: "Il est essentiel de", tiret cadratin, vouvoiement.

## D. Quora & Pinterest

- **Quora:** officially eliminated its anti-self-promotion policy; spam = traffic-driving with no value. Full answer first, one relevant disclosed link. Quora pt-BR is unusually active — real channel for Brazil.
- **Pinterest:** aggressive auto domain-blocking. ≤1 pin per URL per day (ideally per 2–3 days). Claim/verify the domain in Pinterest business settings BEFORE pinning. Appeal fast if blocked.
