## 🔑 Finding 1 (headline): the live `tr` and `vi` titles are NOT what the repo thinks, and the unqualified title check hid it for 22 days

The standing live-name diff calls `itunes.apple.com/lookup?id=…&country=CC` **without a `lang`
parameter**. That call returns the **en-US** name for several storefronts regardless of what is
localized there, so a storefront whose localized title was replaced reads as "unchanged". Re-running
it `lang`-qualified (each line below confirmed 2×) changes the title-loss count from **three to
five**:

| locale | artifact (`current_metadata.json`) | **live v3.0.0, lang-qualified** | |
|---|---|---|---|
| **tr** | `Manifest: Vision Board ve 369` | 🔴 **`Manifest: Vizyon Panosu`** | **new this run** |
| **vi** | `Vision Board: Biểu Hiện & 369` | 🔴 **`Manifest: Vision Board & 369`** | **new this run** |
| ja | `引き寄せ手帳:ビジョンボード&369の法則` | 🔴 `Manifest: 引き寄せ・ビジョンボード` | known |
| ko | `끌어당김: 비전보드 & 369` | 🔴 `Manifest: 감사일기 & 비전보드` | known |
| ru | `Доска желаний: Манифест 369` | 🔴 `Manifest: Карта желаний` | known |
| he, fi, id, da, ar-SA, pl, de, nl | — | 🟢 **intact, byte-identical to artifact** | ✅ |

📌 **`vi` is a genuine replacement, not an API fallback.** With `lang=vi_VN` the **description and
release notes come back in Vietnamese** while the *name* is the English string — the localization is
live and the title specifically was overwritten.
📌 **`he` is intact** (`מניפסטציה: לוח חזון ו-369`). Note `lang=he_il` returns an error and `lang=he`
is the working code — the code format is inconsistent per locale, which is how this was missed.

🔑 **Immediate, free consequence for the keyword fields.** `vizyon` and `panosu` are now **`tr`
title tokens**, and `manifest` is now a **`vi` title token** — all three are duplicates of the
title, which the 100-char field must never spend characters on:

- **`tr`** — the 10-25 string spends **14 chars** on `vizyon,panosu`. Reallocated to restore
  `bolluk` (#20 pre-v3.0) and `ruhsal` (#25 pre-v3.0), the two tokens the prompt flags as
  confirmed-lost. **Net 0 chars, 2 positions.**
- **`vi`** — the 10-25 string spends **9 chars** on `manifest`. Reallocated to `tuvi` (artifact
  token). **Net −4 chars, 1 position.**

🆕 **A title-duplicate check is now part of string validation** (results in the recommendations
section). It is what caught both of these; the 10-25 set passed length/dupe/space checks and still
wasted 23 characters.

📌 **Artifact provenance, stated precisely.** `asc_client.get_version_localizations()` prefers the
*newest editable* version, `current_metadata.json` was written **2026-10-10** (four days after
v3.0.0 went live), and its names now provably differ from live in five locales — so **it is not a
reading of live v3.0.0 metadata under any interpretation.** It remains the best available record of
the pre-v3.0 field, which is how the recommendations use it, but every "what to drop" line below is
inferential. **Re-pulling it (ship-order item 12, now 18 days outstanding) is the single action that
makes the next several runs exact.**
