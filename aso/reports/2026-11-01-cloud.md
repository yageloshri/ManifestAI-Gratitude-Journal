## 🔑 Finding 1 (headline): eleven of the pre-registered recovery targets are **unreachable by the strings being recommended** — including three one-app pools

Every run since 10-16 has pre-registered recoveries (`es numeros angelicos` → #2, `il שיטת 369` →
#1, `ru ангельские числа` → #2–#4 …) and published a keyword string said to deliver them. This run
checked, mechanically, whether each target phrase can actually be *matched* by the proposed string
plus the live title plus the subtitle — word by word, with diacritic folding. **Eleven cannot.**

| target | pool | why the proposed string cannot match it |
|---|---|---|
| 🔑 **`il שיטת 369`** | **1** | `שיטת` is in **no** field, title or subtitle token |
| 🔑 **`es numeros angelicos`** | **1** | field has `numeroangelical` — **singular, and `angelical` ≠ `angelicos`** |
| 🔑 **`mx numeros angelicos`** | **1** | same |
| 🔑 **`pl liczby anielskie`** | **2** | field has `aniolskieliczby` — **wrong word (`aniolskie`), wrong order** |
| **`ru ангельские числа`** | **3** | field has `ангелы`; neither `ангельские` nor `числа` present |
| **`pt numeros dos anjos`** | **4** | field has `numeroangelical`; none of `numeros`/`dos`/`anjos` |
| **`sa ارقام الملائكة`** | **6** | `الملائكة` present, **`ارقام` absent** |
| **`br numeros dos anjos`** | **7** | same as `pt` |
| **`no visjonstavle`** | **12** | token was deliberately left out; it is **#8 and sliding** |
| **`il חוק המשיכה`** | **18** | field has `חוק`+`משיכה`; the query word is `המשיכה` (definite article) |
| **`ru манифест`** | **19** | live `ru` title is `Manifest: Карта желаний` — **Latin** `Manifest`, not Cyrillic |

🔑 **The matching model, now pinned down from this dataset rather than assumed.** Three facts, each
with a live example:
1. **Concatenated tokens DO match space-separated queries.** `es ley de atracción` ranks **#88** and
   the only candidate token is `leydeatraccion`. So concatenations are not the bug.
2. **Diacritics fold.** The same row ranks for `atracción` against `atraccion`; `br lei da atração`
   ranks **#79** against `leidaatracao`. **So `método`/`metodo` and `visualizacao`/`visualização`
   pairs are redundant and waste characters.**
3. 🔑 **Inflection does NOT fold.** `angelical`→`angelicos`, `aniolskie`→`anielskie`,
   `משיכה`→`המשיכה`, `ангелы`→`ангельские` all fail. **This is the whole bug.** Four of the eleven
   misses are a singular/plural or construct-form mismatch inside a token that *looks* right.

📌 **Why this survived twenty runs: the rationale was diffed against the artifact, never against the
query.** "Restores `numeroangelical` (→ `numeros angelicos` pool **1**)" reads as a claim about a
pool; it is in fact a claim about morphology, and it is false. **Added to validation: every
pre-registered target is now checked word-by-word against the proposed string.** All eleven are
fixed in the strings below, at a cost of **zero** net characters in 5 of 8 locales.
